# DNN 攻击：可执行说明

> **预处理、模型与完整预测流程**
>
> - **输入预处理**：按固定规则转换 Challenge，不需要训练。`raw` 模式的逐位数值映射和 `apuf` 模式的阶段特征转换都属于预处理。
> - **预测模型**：DNN 使用各层可训练的权重和偏置计算预测结果，参数通过损失函数指导更新。
> - **完整预测流程**：由“输入预处理 + 已训练网络”共同组成。预测新的 Challenge 时，必须采用与训练时相同的输入模式。

实验中，**预测模型**是较深的神经网络及其学到的权重和偏置；**目标函数（损失函数）**指导网络训练；**准确率**评价训练后模型的预测效果。本项目的 DNN 是具有三个隐藏层的全连接 MLP，用于与较浅的 MLP 比较。

## 一、实验数据与划分

本实验面向单 APUF。当前 DNN 入口读取合并的 CRP NPY 文件，前面的列为 Challenge，最后一列为 0/1 Response；真实 PUF 权重和权重生成种子不参与训练。

[attacks/common.py](../attacks/common.py) 检查形状和二进制取值，再通过 `split_by_response()` 按响应类别分层：分别打乱 0 类与 1 类行号，按测试比例留出样本，再合并并打乱两侧顺序。每类至少有两条样本，测试数量向上取整，同时保留至少一条训练样本。

保持数据内容、行顺序、测试比例和划分种子一致，可以得到与 LR、MLP 相同的划分。当前 500 条 APUF 数据在测试比例 `0.25` 下，得到 375 条训练、125 条测试。Challenge 与 Response 必须始终按行配对，重复输入也需在评估未见 Challenge 前检查。详细步骤见 [LR 数据划分说明](LR攻击说明.md#11-如何划分训练集和测试集)。

## 二、预测模型：结构与初始参数

[attacks/apuf_dnn.py](../attacks/apuf_dnn.py) 将三个隐藏层的宽度 `(128,64,32)` 传给 [attacks/neural_net.py](../attacks/neural_net.py) 中的 `BinaryMLP`。64 位 Challenge 对应结构为：

```text
64 个输入 → 128 个隐藏神经元 → 64 个隐藏神经元
          → 32 个隐藏神经元 → 1 个输出
```

隐藏层使用 ReLU，输出层使用 Sigmoid。默认 `raw` 模式将输入从 0/1 映射到 -1/+1；选择 `--features apuf` 时，改用去掉常数列的 APUF 阶段特征。输入维度和网络结构保持相同，优化原理、代码和对照命令见 [MLP 与 DNN 优化说明](MLP与DNN优化说明.md)。

最终预测模型由**输入处理、网络结构、各层权重与偏置、激活函数和判决阈值**组成。与浅层 MLP 相比，主要改变是隐藏层数量与宽度，训练实现和评价方式共用；更深的结构是否有收益，要由相同测试集上的结果判断。

### 2.1 神经元如何设置，参数量是多少

输入节点数由 Challenge 位数决定，三个隐藏层分别固定为 128、64、32 个神经元，输出层为 1 个神经元。隐藏层逐层处理输入，最终输出 Response 为 1 的概率；输入节点本身不单独设置待学习参数。

对于 64 位 Challenge，参数构成为：

- **输入层到第一个隐藏层**：权重形状 `(64,128)`，有 8192 个权重；偏置形状 `(1,128)`，有 128 个偏置，共 **8320 个参数**。
- **第一个到第二个隐藏层**：权重形状 `(128,64)`，有 8192 个权重；偏置形状 `(1,64)`，有 64 个偏置，共 **8256 个参数**。
- **第二个到第三个隐藏层**：权重形状 `(64,32)`，有 2048 个权重；偏置形状 `(1,32)`，有 32 个偏置，共 **2080 个参数**。
- **第三个隐藏层到输出层**：权重形状 `(32,1)`，有 32 个权重；偏置形状 `(1,1)`，有 1 个偏置，共 **33 个参数**。

**总计 18689 个可训练参数。** 这里包括所有层的权重和偏置，属于攻击网络的参数；若 Challenge 位数改变，第一层权重矩阵和总参数量也会改变。

当前结构由 `attacks/apuf_dnn.py` 中的 `hidden_layers=(128,64,32)` 指定，用于与较浅的 MLP 做实验对比，尚未通过搜索确定为最优结构。DNN 的参数量大于当前 MLP，但是否改善预测能力，应结合相同测试集上的准确率判断。

### 2.2 初始权重如何选择

每层按其输入宽度，用零均值正态分布随机初始化权重，偏置初始化为零。代码采用 He 初始化规则，并对包括输出层在内的各层使用同一规则：

```python
# 创建固定种子的随机数生成器，用于复现初始权重
rng = np.random.default_rng(seed)
# 每层分别按输入宽度设置权重尺度，矩阵连接本层输入与输出神经元
weight = rng.normal(0.0, np.sqrt(2.0 / fan_in), size=(fan_in, fan_out))
# 为本层每个输出神经元设置一个初始值为 0 的偏置
bias = np.zeros((1, fan_out), dtype=np.float64)
```

这是初始化步骤的关键代码，实际参数存入 `self.weights` 和 `self.biases`。随机权重使各神经元从不同状态出发；根据输入宽度设置尺度，配合 ReLU 隐藏层使用，避免任意指定过大的初始权重。

`--seed` 固定划分和网络初始化，两处各自创建随机数生成器；训练批次打乱使用 `seed + 1`。增加层数会改变参数形状，因此 DNN 与浅层 MLP 即使种子相同，也不表示初始权重相同。

## 三、目标函数：误差与参数更新

### 3.1 为什么使用二元交叉熵

预测任务仍是二分类，输出仍是响应为 1 的概率，因此与 MLP 一样使用二元交叉熵。预测接近训练标签时损失小，偏离标签时损失大；错误预测越确定，受到的惩罚越大。

增加网络深度不需要改变这个目标函数。当前没有 L2 正则化或 Dropout，代码直接使用交叉熵对应的梯度，不逐轮计算和保存损失值。

### 3.2 如何计算误差并传回各层

每批样本先经过全部隐藏层和输出层，得到概率，然后形成输出端误差信号：

```python
# 输出概率与标签之差作为反向传播的起点，再逐层传回隐藏层
delta = activations[-1] - batch_y
```

反向传播从输出层开始，逐层计算各层参数对损失的梯度。相邻层的权重负责传递梯度，ReLU 的激活状态决定哪些位置继续传递。这样，每层都能依据最终预测误差得到自己的调整方向，不是仅修改最后一个输出层。

概率与标签之差是梯度计算的起点，不是准确率；它描述偏离程度，而不是只计数预测对错。

### 3.3 如何更新参数及停止训练

使用与 MLP 相同的 Adam 更新器。它为每一层的权重和偏置维护梯度统计量，经偏差校正后更新参数：

```python
# 用 Adam 校正后的一阶、二阶梯度统计量更新当前层权重
# learning_rate 控制更新幅度，epsilon 避免分母为 0
self.weights[layer] -= learning_rate * corrected_weight_moment / (
    np.sqrt(corrected_weight_variance) + epsilon
)
```

偏置同样更新。Adam 系数为 `0.9`、`0.999`，稳定项为 `1e-8`；默认学习率为 `0.001`。

每轮打乱训练样本，默认按 64 条一批执行前向计算、反向传播和参数更新。默认 300 轮表示遍历训练集 300 次，每批都会更新一次。当前达到设定轮数后停止，没有按验证损失提前停止的机制。

## 四、准确率：结果产生与衡量

训练结束后固定整个网络，用相同输入处理预测训练集和测试集。输出概率大于或等于 `0.5` 判为 1，否则判为 0：

```python
# 固定训练好的所有层参数，以 0.5 为阈值将测试概率转换为整数 0/1
test_predictions = (model.predict_proba(test_x) >= 0.5).astype(np.uint8)
# 将预测与测试标签逐条比较，返回预测正确的比例
test_accuracy = accuracy(test_y, test_predictions)
```

准确率为“预测正确条数 ÷ 样本总数”。训练准确率衡量对已用样本的拟合程度，测试准确率衡量保留样本上的预测能力；测试标签只用于核对，不参与反向传播。

比较浅层 MLP 与 DNN 时，先固定同一数据与划分，再比较两侧准确率并注明训练轮数、批次大小和学习率。若 DNN 只提高训练准确率而没有提高测试准确率，就不能据此认为更深结构改善了攻击效果。需要调参时，应另用验证集，避免利用最终测试结果反复选择配置。

## 五、运行与实际产物

在项目根目录、已安装主项目依赖的环境中执行：

```powershell
# 使用三个隐藏层的 DNN 读取 CRP，训练 300 轮，每批 64 条
# Adam 学习率为 0.001，测试比例为 0.25；seed=42 固定划分和初始化
python -m attacks.apuf_dnn --crp-path data/apuf/n64_w42_c42_m500_run01/crps.npy --epochs 300 --batch-size 64 --learning-rate 0.001 --test-size 0.25 --seed 42
```

- `--crp-path` 指定 CRP；省略时使用 `puf.toml` 的默认数据路径。
- `--epochs`、`--batch-size`、`--learning-rate` 默认分别为 `300`、`64`、`0.001`。
- `--test-size` 默认 `0.25`，`--seed` 默认 `42`；`--config` 可指定项目配置。
- 隐藏层结构当前由入口固定为 `(128,64,32)`，不能通过 CLI 修改。
- `--features` 选择输入表示：默认 `raw`，优化模式为 `apuf`；网络结构和训练设置不随模式改变。

**训练产物**是内存中的各层权重和偏置；**终端输出**是网络结构、样本数、训练和测试准确率。当前 CLI 不保存预测模型、预测数组或损失曲线。

本配置首先用于单 APUF。更深网络具有更复杂的表达能力，但不能直接推断它对 XOR-PUF 的攻击效果，需要对应数据上的独立实验。数据准备见 [Challenge/CRP 数据流程](Challenge与CRP数据流程.md)。
