# MLP 攻击：可执行说明

> **预处理、模型与完整预测流程**
>
> - **输入预处理**：按固定规则转换 Challenge，不需要训练。`raw` 模式的逐位数值映射和 `apuf` 模式的阶段特征转换都属于预处理。
> - **预测模型**：MLP 使用各层可训练的权重和偏置计算预测结果，参数通过损失函数指导更新。
> - **完整预测流程**：由“输入预处理 + 已训练网络”共同组成。预测新的 Challenge 时，必须采用与训练时相同的输入模式。

实验中，**预测模型**是多层感知机及其学到的权重和偏置；**目标函数（损失函数）**指导网络训练；**准确率**评价训练后模型的预测效果。训练的目标是得到能根据 Challenge 预测 Response 的模型。

## 一、实验数据与划分

本实验面向单 APUF，输入为二维 CRP NPY 文件，前面的列是 Challenge，最后一列是 0/1 Response。当前 MLP 入口只读取合并后的 CRP，不读取真实 PUF 权重或生成种子。

[attacks/common.py](../attacks/common.py) 检查数据形状和二进制取值，并通过 `split_by_response()` 划分训练和测试样本：分别打乱 0 类、1 类行号，按比例从各类留出测试样本，再合并并打乱两侧顺序。两类各至少需要两条，每类测试数量向上取整，并保留至少一条训练样本。

相同数据内容与行顺序、相同 `--test-size` 和 `--seed`，会得到与 LR、DNN 相同的划分。当前 500 条 APUF 数据在测试比例 `0.25` 下，得到 375 条训练、125 条测试。不能独立打乱 Challenge 与 Response；重复 Challenge 也需在评估未见输入前检查。详细划分步骤见 [LR 数据划分说明](LR攻击说明.md#11-如何划分训练集和测试集)。

## 二、预测模型：结构与初始参数

入口 [attacks/apuf_mlp.py](../attacks/apuf_mlp.py) 选择一个含 64 个神经元的隐藏层；结构和训练代码位于 [attacks/neural_net.py](../attacks/neural_net.py) 的 `BinaryMLP` 类中，由 NumPy 实现。

64 位 Challenge 对应的结构为：

```text
64 个输入 → 64 个隐藏神经元（ReLU）→ 1 个输出（Sigmoid）
```

默认 `raw` 模式将原始 Challenge 从 0/1 映射到 -1/+1；可选择 `--features apuf`，改用去掉常数列的 APUF 阶段特征。两种模式都保持 64 个输入，隐藏层使用 ReLU，输出层给出 Response 为 1 的概率估计。按有权重的层计数，这是 2 层网络；写成“一个隐藏层的 MLP”可避免计数歧义。优化原理、代码和对照命令见 [MLP 与 DNN 优化说明](MLP与DNN优化说明.md)。

最终预测模型由**输入处理、网络结构、各层权重与偏置、激活函数及判决阈值**组成。

### 2.1 神经元如何设置，参数量是多少

输入神经元数量由 Challenge 位数决定，64 位输入对应 64 个输入节点；隐藏层固定为 64 个神经元，输出层只有 1 个神经元，输出 Response 为 1 的概率。输入节点本身不单独设置待学习参数，参数位于层间连接和各层偏置中。

对于 64 位 Challenge，参数构成为：

- **输入层到隐藏层**：权重矩阵形状 `(64,64)`，有 4096 个权重；隐藏层偏置形状 `(1,64)`，有 64 个偏置，共 **4160 个参数**。
- **隐藏层到输出层**：权重矩阵形状 `(64,1)`，有 64 个权重；输出偏置形状 `(1,1)`，有 1 个偏置，共 **65 个参数**。

**总计 4225 个可训练参数。** 它们是攻击网络的权重和偏置，与目标 APUF 的 65 个等效权重参数是不同的对象。若 Challenge 位数改变，第一层权重矩阵和总参数量也会改变。

当前隐藏层宽度由 `attacks/apuf_mlp.py` 中的 `hidden_layers=(64,)` 指定，是本项目采用的实验配置，尚未通过搜索确定为最优结构。增加神经元会增加模型容量和参数量，实验应结合测试准确率判断是否有收益。

### 2.2 初始权重如何选择

各层权重随机初始化，偏置初始化为零。当前代码按每层输入宽度设置随机权重的尺度，使用均值为零的正态分布；这是代码采用的 He 初始化方式：

```python
# 创建固定种子的随机数生成器，用于复现初始权重
rng = np.random.default_rng(seed)
# fan_in/fan_out 是本层输入/输出宽度；按输入宽度设置随机权重尺度
weight = rng.normal(0.0, np.sqrt(2.0 / fan_in), size=(fan_in, fan_out))
# 为本层每个输出神经元设置一个初始值为 0 的偏置
bias = np.zeros((1, fan_out), dtype=np.float64)
```

这里是初始化步骤的关键代码，实际参数存入 `self.weights` 和 `self.biases`。随机权重使隐藏神经元从不同状态出发，避免全部相同的参数和更新；尺度随输入宽度调整，配合 ReLU 隐藏层使用。代码对输出层也采用同样的权重初始化规则。

`--seed` 固定数据划分和网络初始化，两处各自创建随机数生成器；训练批次的打乱使用 `seed + 1`。这些种子控制攻击实验，不提供目标 PUF 的真实参数。

## 三、目标函数：误差与参数更新

### 3.1 为什么使用二元交叉熵

Response 为二分类标签，输出层为 Sigmoid 概率，所以训练使用二元交叉熵。预测概率靠近真实标签时损失小，偏离时损失大；它会更强地惩罚高置信度的错误预测。

当前实现没有加入 L2 正则化或 Dropout。代码直接使用交叉熵对应的梯度，不逐轮计算和保存损失值。训练损失的作用是指导参数学习，准确率的作用是评价预测结果。

### 3.2 如何计算误差并传回各层

每个训练批次先执行前向计算，得到输出概率，再与标签比较：

```python
# 最后一层的预测概率减去本批次的 0/1 标签，得到输出端梯度信号
delta = activations[-1] - batch_y
```

这是 Sigmoid 与交叉熵组合得到的输出端梯度信号。随后反向传播将误差信号从输出层传向隐藏层，计算各层权重和偏置的梯度；ReLU 只让正输入位置传递对应的梯度。

输出概率与标签之差不是最终的“错误条数”。它保留了偏离程度，让程序知道各参数应向哪个方向调整。

### 3.3 如何更新参数及停止训练

使用 Adam 更新各层权重和偏置。它累计梯度的一阶、二阶统计量，经偏差校正后调整更新幅度。权重更新的关键代码为：

```python
# 使用 Adam 校正后的梯度统计量更新本层权重
# learning_rate 控制更新幅度，epsilon 避免分母为 0
self.weights[layer] -= learning_rate * corrected_weight_moment / (
    np.sqrt(corrected_weight_variance) + epsilon
)
```

偏置采用相同方式更新。当前 Adam 的系数为 `0.9`、`0.999`，稳定项为 `1e-8`，默认学习率为 `0.001`。

每轮先打乱训练样本，再按默认批次大小 64 分批更新。`epochs=300` 表示遍历训练集 300 轮，不是仅更新 300 次；每个批次都会更新一次。当前训练达到设定轮数后停止，没有基于损失或验证集的提前停止机制。

## 四、准确率：结果产生与衡量

训练完成后固定全部权重和偏置，按同样的输入处理预测训练和测试数据。输出概率大于或等于 `0.5` 判为 1，否则判为 0：

```python
# 固定训练好的网络，以 0.5 为阈值将测试概率转换为整数 0/1
test_predictions = (model.predict_proba(test_x) >= 0.5).astype(np.uint8)
# 将预测与测试标签逐条比较，返回预测正确的比例
test_accuracy = accuracy(test_y, test_predictions)
```

准确率为“预测正确条数 ÷ 样本总数”。训练准确率反映对已用样本的拟合程度；测试准确率反映保留样本上的预测能力。测试标签不参与反向传播或参数更新。

训练准确率高但测试准确率低，说明在当前划分下的泛化表现较差。比较 LR、MLP、DNN 时，应使用同一批数据和相同划分，报告样本量与两侧准确率；若需调参，应另用验证集，避免反复使用最终测试结果选择模型。

## 五、运行与实际产物

在项目根目录、已安装主项目依赖的环境中执行：

```powershell
# 读取 CRP，训练 300 轮，每批 64 条，Adam 学习率为 0.001
# 测试比例为 0.25；seed=42 固定划分和初始化，批次打乱使用 seed+1
python -m attacks.apuf_mlp --crp-path data/apuf/n64_w42_c42_m500_run01/crps.npy --epochs 300 --batch-size 64 --learning-rate 0.001 --test-size 0.25 --seed 42
```

- `--crp-path` 指定 CRP；省略时使用 `puf.toml` 的默认数据路径。
- `--epochs`、`--batch-size`、`--learning-rate` 默认分别为 `300`、`64`、`0.001`。
- `--test-size` 默认 `0.25`，`--seed` 默认 `42`；`--config` 可指定项目配置。
- 隐藏层结构当前由入口指定，不能通过 CLI 修改。
- `--features` 选择输入表示：默认 `raw`，优化模式为 `apuf`；网络结构和训练设置不随模式改变。

**训练产物**是内存中的网络权重和偏置；**终端输出**是模型结构、样本数、训练和测试准确率。当前 CLI 不保存预测模型、预测数组或训练损失曲线。

这个配置首先用于单 APUF。MLP 具有非线性表达能力，但是否能有效预测 XOR-PUF，需要在对应数据上单独训练和评估。数据准备见 [Challenge/CRP 数据流程](Challenge与CRP数据流程.md)。
