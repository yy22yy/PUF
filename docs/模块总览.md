## 推荐运行顺序

在仓库根目录运行。PowerShell 示例：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e .
python -m challenge_data --num 10000 --c_bit 32 --seed 42 --path data/challenges.npy --overwrite
python generate_crp.py --challenge-path data/challenges.npy --response-path data/responses.npy --seed 42 --challenge-seed 42
python merge_crp.py --challenge-path data/challenges.npy --response-path data/responses.npy --output-path data/crps.npy
python -m attacks.apuf_lr --crp-path data/crps.npy --seed 42
```

此流程会写入 `data/`，并在生成 Challenge、Response 和 CRP 时同时创建同名 CSV。若目标文件已存在，Challenge 生成命令需带 `--overwrite`。LR、MLP 和 DNN 的入口见[基线攻击说明](基线攻击说明.md)。ECP 需要单独安装 PyTorch 或 TensorFlow，见[ECP 说明](ECP攻击说明.md)。

## 常用文件速查

```text
pyproject.toml                  主项目依赖
puf.toml                        默认数据与运行目录配置
project_config.py               配置查找与路径解析
challenge.py                    内存中生成 Challenge
challenge_data.py               Challenge 保存、读取与命令行入口
generate_crp.py                 用 APUF 仿真 Response，并记录元数据
merge_crp.py                    合并 Challenge 与 Response
puf/                            PUF 模型、特征与演示
attacks/                        LR、MLP、DNN 与通用数据处理
attacks/ecp/                    ECP 训练、后端、记录、评估和对比
ecp_trn_minimal.py              独立的 PyTorch 教学实现
```

`run.py` 是固定参数的 Challenge 生成/读取示例；批量生成数据时建议使用 `challenge_data.py` 的命令行入口。`ecp_trn_minimal.py` 是独立教学原型，正式 ECP 实验流程使用 `attacks.ecp`。
