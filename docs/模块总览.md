# PUF 项目模块与运行入口

本文按代码职责梳理模块，并给出可执行入口。文档导航见文末。

## 目录结构

```text
PUF/
├── puf/              PUF 模型与特征（APUF、XORAPUF、ChallengeFeatureTransformer）
├── attacks/          LR / MLP / DNN 基线 + ECP（attacks/ecp/ 双后端）
├── pufkit/           基础设施：配置、落盘约定、Challenge 与 CRP 数据流程
├── experiments/      可复现实验脚本（每个实验一个入口，产出写到 runs/）
├── examples/         独立教学示例（不参与正式实验）
├── tests/            unittest 用例
├── docs/             中文说明文档
├── data/             已生成的 CRP 数据，按 PUF 类型与运行编号分目录
├── runs/             实验产物（本地生成，不入库；契约见 runs/README.md）
├── archive/          历史产物归档（含不可重跑的实验，附 PROVENANCE）
├── papers/           论文研读资料（PDF、翻译、复现笔记）
├── puf.toml          数据与运行目录配置
└── pyproject.toml    依赖与工具配置
```

## 四个板块

| 板块 | 主要代码 | 说明 |
| --- | --- | --- |
| PUF 模型与特征 | `puf/`（4 个模块） | APUF、XOR-APUF、特征转换、`python -m puf` 权重查看 |
| 数据流程与配置 | `pufkit/`（4 个模块） | Challenge 生成/读写、Response 仿真、CRP 合并、路径解析 |
| LR/MLP/DNN 基线 | `attacks/apuf_{lr,mlp,dnn}.py`、`attacks/neural_net.py`、`attacks/common.py` | NumPy 实现，无需额外依赖 |
| ECP 攻击 | `attacks/ecp/`（8 个模块） | PyTorch/TensorFlow 双后端、评估、对比、记录 |
| 可复现实验 | `experiments/` | 每个脚本 = 一个可重跑实验，写 `runs/<id>/` |

## 常用文件速查

```text
puf.toml                        默认数据与运行目录
pyproject.toml                  依赖（含 dev / torch / tensorflow 可选组）
pufkit/config.py                配置查找与路径解析
pufkit/io.py                    .npy + .csv 写入约定、sha256 摘要
pufkit/challenge.py             Challenge 生成、保存、读取
pufkit/crp.py                   Response 仿真与 CRP 合并
puf/                            PUF 模型、特征与命令行初始化
attacks/                        LR、MLP、DNN 与通用数据处理
attacks/ecp/                    ECP 训练、后端、记录、评估和对比
experiments/ecp_train_sizes.py  训练规模扫描（可重跑）
examples/ecp_trn_minimal.py     独立 PyTorch 教学实现
```

`project_config.py` 是兼容 shim，只为旧的 `from project_config import ...` 保留；
新代码请用 `from pufkit.config import ...`。

## 推荐运行顺序

在仓库根目录执行（POSIX）：

```bash
RUN=data/apuf/n64_w42_c42_m500_run01

python -m puf --n 64 --seed 42                       # 查看 64 位 APUF 权重
python -m pufkit.challenge --num 500 --c_bit 64 --seed 42 --path "$RUN/challenges.npy"
python -m pufkit.crp generate --challenge-path "$RUN/challenges.npy" \
    --response-path "$RUN/responses.npy" --challenge-seed 42 --seed 42
python -m pufkit.crp merge --challenge-path "$RUN/challenges.npy" \
    --response-path "$RUN/responses.npy" --output-path "$RUN/crps.npy"
python -m attacks.apuf_lr --crp-path "$RUN/crps.npy" --seed 42
```

ECP 需要单独的环境（`.venv-torch` 或 `.venv-tensorflow`），见 [ECP 攻击与教学示例](ECP攻击说明.md)。
