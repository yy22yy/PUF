# LR、MLP、DNN 基线攻击总览

三种攻击都使用单 APUF 的 CRP 数据训练模型，并保留测试集评估泛化能力。各攻击入口、特征表示和模型结构不同，详细步骤见独立说明：

- [LR 攻击说明](LR攻击说明.md)
- [MLP 攻击说明](MLP攻击说明.md)
- [DNN 攻击说明](DNN攻击说明.md)

## 共用文件

- `attacks/common.py`：检查 CRP、按 Response 分层划分训练集和测试集，并计算准确率及多数类基线。
- `project_config.py`、`puf.toml`：解析默认 CRP 路径和项目配置。
- `attacks/apuf_lr.py`：LR 的特征转换、训练及命令行入口。
- `attacks/apuf_mlp.py`、`attacks/apuf_dnn.py`：两个网络结构的命令行入口。
- `attacks/neural_net.py`：MLP 与 DNN 共用的 NumPy 网络、反向传播和 Adam 更新实现。

## 输入数据

默认读取 `puf.toml` 中的 `default_crp`，也可在每条攻击命令中指定 `--crp-path`。CRP 必须是二维 NPY 数组，每行依次为 Challenge 各位和最后一位 Response；值只能为 0 或 1，Response 中的 0、1 两类都至少要有两条样本。

没有 CRP 时，先按[Challenge/CRP 数据流程](Challenge与CRP数据流程.md)生成。三种入口均通过 `--seed` 固定数据划分；完整训练参数可用对应命令的 `--help` 查看。

这些入口会在终端报告训练准确率、测试准确率和测试集多数类基线，不会自动保存模型或建立 ECP 格式的实验记录。
