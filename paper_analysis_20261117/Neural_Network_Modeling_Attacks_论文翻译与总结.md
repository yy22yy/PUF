## 摘要

**摘要——** 通过重温、改进并扩展文献中针对 XOR Arbiter PUF 的基于神经网络的建模攻击，我们表明：XOR Arbiter PUF、(XOR) 前馈（Feed-Forward）Arbiter PUF 以及 Interpose PUF 可以被**更快**地攻击，攻击可达到**更大的安全参数**，且所需的激励-响应对（challenge-response pair，CRP）数量比此前已知结果**少一个数量级**。这一结论同时适用于仿真数据和硅片（silicon）数据。为支撑这一主张，我们讨论了最近提出的各种建模攻击之间的异同，并用流行的机器学习框架 **Keras** 统一实现所有这些攻击，进而将它们的性能与已被充分研究的 **Logistic 回归（LR）攻击**进行公平比较。我们的发现表明：基于神经网络的建模攻击有潜力在 PUF 上超越传统建模攻击，因此**必须成为 PUF 安全性分析标准工具箱的一部分**；本文的代码与讨论可作为将我们的结果扩展到本文范围之外的 PUF 设计的基础。

**关键词——** 物理不可克隆函数（PUF）、强 PUF、机器学习、建模攻击、Arbiter PUF。

## I. 引言

在今天所有实际部署的密码学应用中，区分合法用户与攻击者的依据是**秘密密钥**的知识；密钥无处不在，包括嵌入在数字门禁钥匙、信用卡和护照里的微观尺度计算机中。随着密码学日益普及，获取秘密密钥本身成为一种重要攻击策略，因为密钥一旦泄露，所用方案的安全保障就会崩塌。

为了缓解这类攻击，出现了 **物理不可克隆函数（PUF）** 这一研究分支。其思想是：合法用户与攻击者的区别不再由“知识”定义，而由对**物理实体的占有**定义。这个被称为 **PUF token** 的物理对象，在接受物理刺激（如电信号或激光束）时表现出高度个体化的物理行为；并且它被假设在物理上不可克隆，即本质上不可能造出两个完全相同的 token。设想的密码学方案就建立在这种**每个不可克隆 token 独有的响应行为**之上，而非存储在存储器中的经典秘密。

此类基于 PUF 的“免秘密”密码学虽然从定义上免疫于“恢复密钥”类攻击，但攻击者仍可能研究某个 PUF token 的个体行为，并用**数学模型外推**它——这种情况下，远端无法区分原始 PUF token 与数学模型的差别。若此类**建模攻击**成功，大多数应用的安全性就会崩溃，就像密钥泄露一样。（注意：反过来，无法成功建模某 PUF 本身并不保证其安全。）

发起建模攻击的重要工具是**机器学习**——一种高度参数化的、用专门算法从观测数据生成预测的方法。过去二十年，机器学习已成为 PUF 安全性分析的首选工具，攻击者试图建立某个 PUF token 的模型，若成功则可高精度预测 PUF 响应。因此，建模攻击研究是 PUF 与免秘密密码学研究的核心组成部分。随着机器学习框架（如 TensorFlow/Keras、Torch）的快速发展，预计这一趋势会长期持续。

传统上，基于机器学习的强 PUF 建模攻击大多建立在**物理启发模型**的参数优化之上。近来，这一方法得到了另一种**通用模型**建模攻击方法的补充——即不依赖物理洞察的通用模型。此意义上，“通用模型”不再局限于由物理启发的某类函数，而是能对任意布尔函数建模。因此，这类攻击不需要对被攻击 PUF 精确建模，并能快速测试 PUF 设计思想。虽然通用模型也能从基于物理洞察的特征选择中受益，但使用像多层感知机（MLP）这样的通用神经网络作为强 PUF 设计的分析工具已经获得一定应用，在分析由多个 Arbiter PUF 组成的设计时尤其有用。例如 Wisiol 等人在最近对 Interpose PUF 的建模攻击中使用这种通用模型证明了：被攻击 PUF 的轻微变形也不是安全强 PUF 的候选。Santikellur 等人用 MLP 方法研究 MPUF、cMPUF、rMPUF、轻量安全 PUF、XOR Arbiter PUF 和 Interpose PUF 的安全性。SCA-PUF 的作者表明其设计相对于 XOR Arbiter PUF 更能抵抗基于神经网络的攻击。Venkatesh 等人在其基于亚阈值分压器阵列的新 PUF 设计中，用一个“失败的” MLP 建模攻击作为其安全性的证据。

基于神经网络的建模攻击的快速发展和流行，引发了对这类通用模型所得结果意义的质疑。要评估某 PUF 设计的安全水平，尤为重要的事有三点：其一，通用神经网络攻击的数据与时间复杂度与更专门的物理模型攻击相比如何；其二，两类攻击的成功几率如何；其三，这类攻击的各种超参数应如何配置。

本文针对 **Arbiter PUF 及其变体**（PUF 研究中常用作对比基线或新设计构建块的一族电学 PUF）回答上述问题。借助本文的贡献，其他研究者可以对其他 PUF 设计开展类似分析。具体而言，我们的贡献如下：

1. 我们表明，使用通用神经网络时，XOR Arbiter PUF 可以**更快**、**达到更大的安全参数**、并**以比此前已知少一个数量级的 CRP** 被攻击——即便其实现给出的是可靠（无噪声）响应。由此我们证明神经网络是 PUF 安全性分析中的**必备工具**，并驳斥了 Nguyen 等在 CHES 2019 的相反观点。
2. 我们表明，我们的结果**降低了 Interpose PUF 上分割攻击（Splitting Attack）的数据复杂度**，并实现了对前馈 Arbiter PUF 的攻击，从而证明神经网络攻击性能的改进其影响超出 XOR Arbiter PUF 本身的安全。
3. 我们**复现了三种基于神经网络的攻击和基于物理模型的 LR 攻击**（均针对 XOR Arbiter PUF），并给出穷尽且公平的性能比较。我们概述并总结了这四种攻击，讨论异同，并论证设计选择。
4. 我们**驳斥了最近声称的 XOR Arbiter PUF 建模攻击极低数据复杂度**[17]。
5. 我们提供了一个**全面、统一、易用的 Python 实现**，涵盖本文所有攻击，在开源许可证下发布于 https://github.com/nils-wisiol/pypuf/tree/2021-mlp，集成进 pypuf 框架[31]。

**文章结构**：第 II 节概述 XOR Arbiter PUF 建模攻击与神经网络建模攻击相关工作；第 IV 节讨论并评估作为对比基线的 LR 攻击；第 V、VI、VII 节复现并扩展文献中的神经网络攻击，讨论设计选择与攻击性能，并在第 VIII 节比较各 XOR Arbiter PUF 攻击；第 VII-D 节将发现应用于 Interpose PUF，第 VII-E 节应用于 XOR Arbiter PUF 硅片数据，第 IX 节应用于 XOR 前馈 Arbiter PUF；第 X 节给出结论与未来工作。

## II. 相关工作

PUF 安全性分析并不限于基于机器学习的建模攻击，也不限于本文所用的攻击者模型。

对 XOR Arbiter PUF，最先进的攻击利用的是**关于响应可靠性（reliability）的信息**——即给定同一 challenge 时 token 返回相同响应的概率[5]。有了这一信息，XOR Arbiter PUF 建模的数据复杂度被大幅降低，甚至优于本文神经网络攻击的结果。近来 Tobisch 等证明该攻击方法可扩展到其他 PUF 设计，并对 Interpose PUF 发起了攻击[26]。Chatterjee 等用基于可靠性的攻击表明，在此攻击者模型下 S-PUF 的安全水平被大幅降低。

与这些工作不同，下文的相关工作考虑的是**更弱的攻击者模型**——只利用响应信息。

高度专用的机器学习攻击同样是 PUF 安全性分析的重要组成部分，如 Delvaux 对带轻量混淆逻辑的 PUF 给出的五种攻击集合。这一思路与本文采用的通用模型形成对照。另一支 PUF 安全性分析使用 **PAC（Probably Approximately Correct，概率近似正确）学习框架**，关注“存在渐近多项式时间学习算法、能以规定成功率给出规定精度模型”的函数类；在某些情况下这无需物理启发模型即可做到，这与本文使用通用神经网络相关。最近还提出了半自动化的分析方法。

## III. 预备知识

### A. 加性时延模型（Additive Delay Model）

如图 1 所示，一个 n 位 k-XOR Arbiter PUF 可用布尔函数 f:{−1,1}ⁿ → {−1,1} 建模，该函数由实数参数 **W ∈ R^{k×n}** 和 **b ∈ R^k** 参数化。对激励 c ∈ {−1,1}ⁿ，响应为：

  **f(c) = sgn( ∏_{l=1}^{k} (⟨Wₗ, x⟩ + bₗ) )**

其中特征向量 **x ∈ Rⁿ** 由 xᵢ = ∏_{j=i}^{n} cⱼ（即 challenge 各比特部分乘积的“ATF/累积乘积”变换）给出。参数 W（本文称为权重）代表某个特定 PUF token 的物理本征；该模型通常称为**加性时延模型**。其物理动机可追溯到 Arbiter PUF 电路的内在时延值。

当 k=1（即普通 Arbiter PUF）时，加性时延模型可理解为 n 维空间中的一个超平面，把布尔立方体 {−1,1}ⁿ（进而 Rⁿ）的棱边按响应 −1、+1 分成两个区域；边界是无偏时的线性子空间、有偏时的仿射子空间。因此该模型是**线性**的。而在 XOR Arbiter PUF 中，Rⁿ 中的决策边界变得更复杂——即 XOR 运算增加了模型的非线性。

Arbiter PUF 模型的线性也正是不使用特征映射 xᵢ=∏cⱼ 则决策边界无法轻易表示为超平面的原因；而这一表示恰是 LR 攻击成功的前提（见第 IV 节）。

**噪声建模**：采用 Delvaux 等的模型。每次求值时，为 Arbiter PUF 两条时延线的时延差加上一个零均值高斯噪声 N：

  **f(c) = sgn(⟨W, x⟩ + b + N)**

对 k-XOR Arbiter PUF，则抽取 k 个相互独立的噪声值。

**可靠性（reliability）** 定义为在独立两次求值中 PUF 返回相同响应的期望：

  **reliability(f) = E_c [ f⁽¹⁾(c) = f⁽²⁾(c) ]**

给定该定义后，可调整噪声方差使仿真的可靠性达到某一目标值。

### B. 攻击者模型

PUF 的标准攻击者模型基于“PUF token 相比传统密钥存储硬件能提供更高安全性”这一承诺。因而在该模型中，攻击者可在有限时间内物理接触 PUF token，从而收集大量 challenge-response 对（期间也允许硬件攻击，但本文不研究）。在此模型下，XOR Arbiter PUF 和 Interpose PUF 可用**每 challenge 可靠性**所暴露的信息来攻击（对同一 challenge 求值多次即可恢复可靠性）。

然而本文考虑的是被复现工作所采用的**更弱的攻击者模型**：被动攻击者只能获得一大批均匀随机 challenge 及其对应响应。这虽然总体上是 PUF 攻击者模型的一种不合理的限定，但它等价于“被攻击 PUF 的可靠性信息不可用或无价值”的情形；这在某些基于 PUF 的认证协议中成立，也可能对某些新设计成立。因此，被动攻击者模型为“神经网络建模攻击应成为 PUF 标准安全性分析的一部分”这一论点提供了合适的基础。不过，由于攻击者模型受限，我们强调：在此模型下攻击失败，本身不能作为安全的证据。

### C. 方法论

为公平比较四种不同机器学习建模攻击在 XOR Arbiter PUF 上的性能，我们用流行的 Keras 框架重写了这些攻击，并在同一 CPU 上运行所有实验；对 Interpose PUF 和前馈 Arbiter PUF 的新攻击也用该框架。由于这些攻击相对较快，我们把注意力集中在**数据复杂度**的比较上——即得到良好建模预测需要多少训练数据。

我们**不重点关注预测质量的精确准确率指标**，原因有二：其一，适当参数化后这些攻击不产生中间结果——即攻击要么以约 50% 准确率、要么以接近 100% 准确率结束；而且高准确率结果还可在多训练几个 epoch 后进一步提高。其二，要冒充 PUF token 并不需要极高准确率，任何显著高于 50% 的预测准确率都应视为该 PUF 设计的安全缺陷[8]。因此，我们关注的不是预测准确率，而是**攻击成功率**：即在相互独立的 PUF 仿真上独立运行的攻击中，预测准确率超过 90% 的比例。由于几乎所有成功攻击的准确率都在 95% 以上、几乎所有失败攻击都在 55% 以下，成功率对这个阈值选择很不敏感。为完整起见，所得模型的预测准确率以若干不同 PUF token 上多次攻击的平均值给出。

为详细保证可复现性，我们为所有伪随机生成器（PUF token 仿真生成、机器学习模型初始化等）都固定了种子（seed）。

## IV. 基线：改进的 Logistic 回归（LR）攻击

本文将三种神经网络建模攻击与 Ruhrmaier 等提出的、在 XOR Arbiter PUF 上广泛使用的 LR 攻击[21]进行对比。LR 攻击已成为基于时延的 PUF 安全性分析的重要工具，被大量工作使用，包括最近的 Interpose PUF 提案及其上的攻击。本文用 Keras 重写 LR 攻击并做了若干修改，作为 XOR Arbiter PUF 攻击对比的基线。

LR 攻击基于 Arbiter PUF 的**物理模型**：把给定 challenge 转换成适当选的特征向量后，该模型可表示为 n 维空间中的超平面。将 XOR 运算改写成对响应值 −1/+1 做实数乘积的可微形式，该 Arbiter PUF 模型可推广到 XOR Arbiter PUF。

我们对原始 LR 算法做了如下改进（以提高训练性能）：
1. **引入 mini-batch**：每个 epoch 内对网络做多次梯度更新（而非每跑完整个训练集才更新一次），从而用更少 epoch 收敛、缩短训练时间；但 batch 不能太小，否则梯度噪声过大会产生无益的更新。
2. **用 Adam 优化器**替代原来的弹性反传（RProp），因为后者与 mini-batch 配合不佳。
3. **对各 Arbiter 链算出的 k 个时延值施加 tanh 激活**，即把模型函数从
   f(c) = tanh( ∏ₗ (⟨Wₗ,x⟩ + bₗ) )
   改为
   **f′(c) = tanh( ∏ₗ tanh(⟨Wₗ,x⟩ + bₗ) )**。
   动机：在传统 LR 网络中，某条 Arbiter 链可能对最终输出的绝对值产生过大影响；但电路中没有“绝对值”这类量，XOR Arbiter PUF 的权重还可以被正标量缩放而不改变函数。施加 tanh 使各条链的影响（因子值被限制在 ±1）更均衡，有助于训练。

（注：由于引入额外 tanh，本攻击严格来说不再是 logistic 回归，本文仍延用“改进 LR 攻击”这一叫法。）

**结果（表 I 要点）**：借助 Keras 与上述改进，LR 攻击的墙钟时间性能显著提升。数据复杂度上，LR 所需训练集 CRP 数量随 XOR 数 k **指数增长**；用最小二乘对 k ↦ α·eᵏ 拟合后预测：k=10 需约 13 亿个 CRP、k=11 需约 36 亿、k=12 需约 10¹²。这与以往研究一致，说明 LR 的数据复杂度无法靠超参数调节显著降低。

## V. Santikellur 等人的张量回归网络攻击（ECP-TRN）

为降低 XOR Arbiter PUF 建模攻击的计算开销，Santikellur 等提出用**高效的 CP 分解张量回归网络（ECP-TRN）**，由整数秩 R 参数化。对 k-XOR n 位 Arbiter PUF，模型计算：

  **f(x) = sgn( Σ_{i=1}^{R} αᵢ · ∏_{l=1}^{k} (⟨w_{i,l}, x⟩ + b_{i,l}) )**

可训练参数为 αᵢ（i=1..R）、w_{i,l}、b_{i,l}（l=1..k），共 nkR + kR + R 个。

该网络可理解为**并行训练 R 个 XOR Arbiter PUF 模型**，最终响应为这 R 个模型输出的加权和再取符号。

**我们的发现**：针对 64 位 4/5/6-XOR 的仿真实验显示，在所有成功训练的网络里，**恰好只有一个**模型与仿真权重高度相关，其余 R−1 个毫无相关；相应地，R−1 个模型的单独预测准确率约 50%，仅一个高准确率。只取那个模型反而比完整网络准确率更高（去掉了低相关模型的噪声）。因此我们结论：**R 秩 ECP-TRN 相比 1 秩模型没有带来收益**。

让“单个 PUF 上多次重跑”与“R 秩单次”对比，结果（表 II）显示：在我们研究的所有情形下，秩 R 的 ECP-TRN 都没有超过“独立跑 R 次秩 1 攻击”的成功率。

**复现**：我们无法完全复现 Santikellur 等的原始结果——64 位 4-XOR 可复现，但 5-XOR、6-XOR 需要显著更多 CRP 才可靠收敛，7-XOR 及以上用高秩模型完全失败。与原作者交流也无改进。我们怀疑原因在于 Keras 与原始 TensorFlow v1 行为差异、或 CRP 生成的差异；也可能原工作并行训练 R 个模型时实际报告的是“多次尝试中的最大准确率”，而本文报告的是接近 100% 成功率所需的数据复杂度。

## VI. Aseeri 等人的多层感知机攻击

继 Yashiro 等对 3-XOR 64 位 Arbiter PUF、Alkatheiri 等对前馈 Arbiter PUF 用 MLP 的工作之后，Aseeri 等是**第一个用神经网络攻击超过 4 条 Arbiter 链的 XOR Arbiter PUF** 的团队。他们强调其攻击可在普通笔记本（无 GPU、内存有限、单核消费级 CPU）上运行，同时相比当时最先进的 LR 攻击（Tobisch & Becker）显著降低了时间与数据复杂度。

此前有人复现 Aseeri 等的工作失败[22]，很可能因为当时源码尚未公开；结果就是其攻击未能充分纳入 Interpose PUF 的安全性分析中[19]。这支持我们“公开攻击结果所依赖的代码应被大力鼓励”的观点。

原实现基于 scikit-learn；本文用 Keras 重写其网络并**成功复现了他们的全部结果**（表 III 汇总，并扩展到 64 位 9-XOR 和 128 位 8-XOR 情形）。原文单核运行，我们最多用 40 核；为便于对比，我们给出单核时间的估算。Aseeri 等未给出超参数设置的论证，相关讨论见第 VII 节。

## VII. Mursi 等人的多层感知机攻击

### A. 神经网络

Mursi 等提出了 MLP 攻击的增强版，声称将 XOR Arbiter PUF 建模攻击的数据与时间复杂度降低了几个数量级。**我们驳斥了其经验结果**，但表明其攻击在有效 CRP 上仍比其它基于响应的 XOR Arbiter PUF 建模攻击需要更少 CRP。

对 n 位 k-XOR Arbiter PUF，Mursi 等使用**三个全连接隐藏层，尺寸为 (2^{k−1}, 2^k, 2^{k−1})**。该设计比 Aseeri 的 MLP 和 Santikellur 的高秩方法使用**更少可训练参数**（利于训练），但仍比传统 LR 攻击多“几个数量级”的参数——例如 64 位 9-XOR 时，LR 有 585 个可训练参数，而本节 MLP 有 66,560 个。

隐藏层用 **tanh**（Aseeri 用 ReLU）。tanh 使下一层输入趋于零均值、利于训练；虽然 Santikellur 等认为 tanh 会遭遇梯度消失，但本网络只有三层、很浅，梯度消失不太可能出现。各攻击超参数对比见表 V。

### B. 复现与结果

我们用 Keras 重写 Mursi 等的攻击，发现**其结果无法复现**。差异被追溯为 **Mursi 等所用 CRP 生成器中的一个 bug**：其基于时延仿真，本应为每个 PUF 实例独立地从均值 300、方差 40 的高斯分布抽取 4n 个时延值，再由 challenge 算出时延差并转为响应；但该 bug 导致**约 20% 的随机时延被无意设为零**。这在 CRP 数据上难以察觉（偏差几乎不受影响，且 MLP 攻击并不会恢复时延或权重、而是一个难以解释的神经网络）。

我们用本文的 pypuf CRP 生成器（无此 bug）研究该攻击，发现：虽然原报告的优异性能很大程度上受益于错误的 CRP 生成，但**在有效 CRP 上，该攻击仍比 LR 攻击在数据复杂度上低一个数量级**，且优势随 XOR 数增加而增大（见图 4），运行时间也得到改善。详细结果见表 IV。

**表 IV 要点（Mursi MLP，验证准确率 95% 早停，成功率多为 10/10）**：
- 完全可靠响应 n=64：k=4 → 150k CRP（<1 min）；k=5 → 200k；k=6 → 2M；k=7 → 4M；k=8 → 6M（13 min）；k=9 → 45M（16 min）；k=10 → 119M（291 min）；k=11 → 325M（1898 min，104 GiB）。
- 完全可靠响应 n=128：k=4 → 1M；k=5 → 1M；k=6 → 10M；k=7 → 30M。
- 完全可靠响应 n=256：k=4 → 6M；k=5 → 10M；k=6 无成功（30M、—）。
- 85% 可靠性 n=64：k=4 → 180k；k=5 → 150k；k=6 → 2M；k=7 → 4M。

对 128、256 位 challenge，数据复杂度随 XOR 数快速增长；但 128 位时仍低于 LR 攻击水平（256 位无文献可对比）。综合来看，**没有证据表明增大 challenge 长度是抵御建模攻击的有效手段**。同时，参数多得多的模型能胜过参数更少的模型，这**推翻了 Nguyen 等“LR 攻击是 XOR Arbiter PUF 攻击中表现最佳”的论断**。

作为复现的副产品，我们发现：**XOR Arbiter PUF 中极小比例的零时延值就能导致建模攻击数据复杂度的显著损失**。因此 PUF 实现者应对“真实数据与仿真攻击结果的明显偏差”格外警惕，并验证所用仿真的有效性。

### C. 超参数优化

技术性说明：该攻击的超参数很难配置。mini-batch 虽利于运行时间，但要求恰当调节学习率。图 2 报告了 8-XOR 64 位（6M CRP）上、不同学习率 × batch 组合的攻击成功率，表明**只有学习率与 batch 的恰当组合才能成功**。我们推测：小 batch + 高学习率时梯度方向噪声太大，难以有效更新；大 batch + 低学习率时在收敛前就耗尽了 epoch 数。

### D. 噪声鲁棒性及对分割攻击的应用

实验发现：**该攻击在有噪情况下依然有效，且数据复杂度相比无噪情况没有显著变化**，这一点令人意外（MLP 不像 LR 那样被限制在某一函数类）。训练仍收敛到期望的 XOR Arbiter PUF 模型并逼近最大预测能力。噪声鲁棒性的详细结果见表 IV。

我们还报告：**MLP 攻击可直接“即插即用”替代 LR 攻击，用于 Interpose PUF 的分割攻击**。类似 XOR Arbiter PUF 的结果，分割攻击的数据复杂度被显著降低：64 位 (1,7)-Interpose PUF 用 **600 万 CRP 在几分钟内**建模（原实现需 2000 万 CRP、20 小时）；64 位 (1,8)-Interpose PUF 用 1800 万 CRP 在**不到 1 小时**内建模。外推表明：MLP 攻击有望用 3.25 亿 CRP 攻破 64 位 (1,11)-Interpose（Wisiol 等原先用 7.5 亿攻 (1,9)），用 6.5 亿 CRP 攻破 64 位 (11,11)-Interpose。

分割攻击本质上要攻击两个 XOR Arbiter PUF：下层用全部 CRP，上层只能用约一半。因此对 (x,x) 规模相当于数据复杂度翻倍，对 x<y 的 (x,y) 无增量。这些结果也表明 MLP 攻击（在一定程度上）对**特征噪声**与**标签噪声**都具鲁棒性。

### E. 对真实数据的应用

我们用 Mursi 等[17]和 Aghaie & Moradi[1] 提供的（XOR）Arbiter PUF 数据集，比较改进 LR 与 MLP 攻击：

- **Mursi 数据**：64 位 k-XOR（k=4..9）各一个实例，k∈{4,5,6} 用 100 万、k∈{7,8,9} 用 500 万个相同 challenge 查询；无重复测量，无法评估可靠性。统计分析确认偏差随 XOR 数增加而减小（4-XOR 平均响应 0.03，9-XOR 为 10⁻⁵）。
- **Aghaie & Moradi 数据**：64 位 (1,5)-Interpose PUF，100 万个均匀随机 challenge，含全部 6 条单独 Arbiter PUF 的响应；有 11 次重复测量（用于计算可靠性，均 ≥99.7%）。攻击只用第一次测量。我们把其中的 5 条 65 位 Arbiter PUF 组合成 65 位 k-XOR（k=1..5）来做 XOR Arbiter PUF 攻击实验。

结果（图 3）：在 Mursi 数据上，k=5、k=7 时 MLP 数据复杂度远低于改进 LR；在 Aghaie & Moradi 数据上，对小 k 的 XOR Arbiter PUF，MLP 攻击要么不合适、要么参数不佳，相对改进 LR 没有优势（与仿真结果一致）。结论：**真实数据上的实验确认了仿真得到的结论**。

## VIII. XOR Arbiter PUF 攻击的比较

在三种神经网络攻击与作为基线的改进 LR 攻击中：Mursi 等的论断可追溯为 CRP 生成错误；在文献中，就我们所知，**Santikellur 等声称了最低的 XOR Arbiter PUF 数据复杂度**，但我们无法在 7-XOR 及更大情形复现。

在本文成功复现的攻击中，**Mursi 等尽管可训练参数较多，数据复杂度最低**——优势来自网络规模与超参数的选择；进一步优化仍可能继续降低复杂度。但再对 XOR Arbiter PUF 优化不会带来新结果（因为它在可靠性攻击下已被攻破）；优化应转向其它 PUF 设计。

与改进 LR 相比，**MLP 只在超过 4 条 Arbiter 链的 XOR Arbiter PUF 上有数据复杂度优势**。Aseeri 与 Mursi 攻击的主要区别是网络形状与隐藏层激活函数：tanh 相比 ReLU 给出零均值输出、利于训练。

本文不做详细运行时间比较（大多数攻击几分钟内完成，难以有效比较；且 Keras 在 CPU/GPU、多线程等不同设置下的时间差异很大），但所有攻击时间对攻击者而言都不算过长。

## IX. 对前馈 Arbiter PUF 的 MLP 攻击

为说明“MLP 攻击应成为强 PUF 设计标准安全性分析的一部分”，我们把攻击应用到**前馈 Arbiter PUF（Feed-Forward Arbiter PUF, FF-APUF）** 及其变体。

前馈 Arbiter PUF 由 Gassend 等和 Lee 等首次提出，其思想是：在信号到达最后一级之前，用额外 arbiter 单元“拾取”延链上的信号，从而在后续级引入非线性；这些 arbiter 单元产生额外的 challenge 比特（称为**前馈环**）。因此前馈 Arbiter PUF 可看作 Interpose PUF 的前身。其扩展为（同质）XOR 前馈 Arbiter PUF：结果比特由 k 个环位置相同的前馈 Arbiter PUF XOR 得到。

前馈 Arbiter PUF 的建模攻击抗性远强于 XOR Arbiter PUF。以往：Ruhrmaier 等只攻击环排列规则的 FF-APUF；Kumar & Burleson 用进化策略攻击硅片中最多 8 环的 FF-APUF，报告的数据复杂度远低于我们的攻击，但未报告 XOR 前馈版本；Alkatheiri & Zhuang 用 MLP，但准确率随环数增加而下降，且**要求攻击者已知环的模式**（实际难以满足）。

**本文方法**：攻击最多 10 环的 n 位 FF-APUF 与 XOR FF-APUF，使用**定尺寸 MLP：四个隐藏层，神经元数分别为 (n, n/2, n/2, n)**；网络形状与超参数**独立于环数与环位置**（即攻击无需知道环信息）；隐藏层用 tanh。继续增加层数反而降低预测能力、增加训练时间。

**硬件**：用 Xilinx Vivado + VHDL 在三块 Artix-7 FPGA 上实现 64 级（stage）FF-APUF，MicroBlaze CPU + AXI UART（230 k波特率）加速 CRP 传输，每块芯片生成 500 万 CRP，环境温度约 22°C、核心电压 1.0V。

**结果**：我们的方法能用，64 级、10 环 FF-APUF 与 64 级、每 Arbiter PUF 5 个同质环的 8-XOR FF-APUF；即便 challenge 长度加倍到约 128 位，攻击性能也无本质变化。仿真结果见表 VI（相对 Alkatheiri，还**无需已知环模式**）、表 VII（k-XOR FF-APUF）。真实数据实验大体确认了 64 位 FF-APUF 的攻击结果（10 环需 77 万 CRP）。

**局限**：对**异质环**（各前馈 Arbiter PUF 用不同环位置）的 XOR FF-APUF，哪怕参数很温和（每 PUF 仅 1 环、k=3），我们的网络也无法建模——准确率饱和在约 60%。我们因此认为，要支持这类扩展，需要对网络结构做大幅修改（更多层/节点或非全连接结构）。

综上，MLP 攻击能够建模此前攻击无法触及的前馈 Arbiter PUF 变体，进一步降低了 FF-APUF 家族的安全水平。

## X. 结论

本文把三种基于神经网络的 XOR Arbiter PUF 建模攻击与改进 LR 基线进行了比较。虽然我们**无法复现**声称“极低数据复杂度”的实验，但结果证明：**即便 Xor Arbiter PUF 的响应完全可靠，也能被更快、以更少 CRP 攻击，并一直攻击到远更大的安全参数**。由于增大 XOR Arbiter PUF 安全参数在工艺上很有挑战，我们的结果进一步让人怀疑“能制造出足够安全水平的 XOR Arbiter PUF”。

我们把四种攻击统一实现、在同一平台上测试，从而给出公平比较，并确认 Mursi 等 MLP 的更好表现不是更好框架或更快 CPU 所致，而是其策略的内在属性。我们还证明神经网络建模攻击能攻击文献中常见安全参数的 (XOR) 前馈 Arbiter PUF；对硅片数据的应用确认了这些优势能迁移到实际实现。

MLP 在数据复杂度与建模能力上的优势让我们得出结论：**基于神经网络的攻击应成为 PUF 安全性分析标准工具箱的一部分**——一方面它能快速测试设计思想，另一方面（如本文所示）能提供更低的攻击时间或数据复杂度。但我们**不建议**用神经网络攻击取代基于物理模型的专门攻击：对 XOR Arbiter PUF，物理启发模型仍与 MLP 攻击密切相关，因为它提供了建模所依赖的**特征**；若完全脱离物理模型知识直接对 challenge 比特用 MLP，除玩具规模的 XOR Arbiter PUF 外都会失败。

我们把 MLP 攻击应用于 Interpose PUF 分割攻击，凸显将其加入 PUF 安全评估工具箱的重要性，并表明本文展示的低数据复杂度对复合 PUF 设计的安全分析也有应用价值。

我们**证伪**了 Mursi 等的“极低数据复杂度”论断并重新评估其结果（该攻击数据复杂度仍比最先进攻击低一个数量级）；也**证伪**了 Nguyen 等“LR 攻击在所有 XOR Arbiter PUF 建模攻击中数据复杂度最低”的论断。

为便利未来的 PUF 安全性分析、避免错误，我们将所有实现作为 pypuf 框架的开源贡献公开，并鼓励 PUF 社区效仿。本文的代码与对攻击方法、超参数选择、网络设计的详细讨论，揭示了 MLP 建模攻击的部分内部机理，有助于把 MLP 方法推广到其它 PUF 设计。

我们的结果还引出问题：像 Tobisch 等的可靠性攻击能否同样受益于神经网络方法；若能，则有望把可靠性攻击推广到 XOR Arbiter PUF（及其变体）之外的设计。最后，在 XOR Arbiter PUF、Interpose PUF、同质 XOR 前馈 Arbiter PUF 都被成功攻击之后，值得期待神经网络攻击还能建模哪些其它 PUF 设计。

# 总结：核心方法、贡献与实验部分

## 一、核心方法

本文的“主角”是一种**通用神经网络（MLP）建模攻击**。它不依赖对 PUF 电路的精确物理建模，而是训练一个多层感知机，把 PUF 当作一个“黑盒”布尔函数 f:{−1,1}ⁿ→{−1,1} 去逼近。方法要点：

1. **特征变换（关键前处理）**：不直接喂原始 challenge 比特，而是做“ATF/累积乘积”变换 xᵢ = ∏_{j=i}^{n} cⱼ。这一特征源自 Arbiter PUF 的加性时延模型，使得线性决策边界能表达为超平面——它是所有后续学习成功的前提。
2. **网络结构镜像 PUF 结构**：对 k-XOR Arbiter PUF，用三层全连接 MLP，隐层规模 (2^{k−1}, 2ᵏ, 2^{k−1})，隐层用 tanh，输出层 tanh 对应 ±1 响应；训练用 Adam + 二元交叉熵 + 自定义早停。网络刻意“像”PUF 本身的组合结构（XOR 的 k 个 Arbiter 链 ↔ 网络的多层非线性）。
3. **统一框架公平对比**：把三种神经网络攻击（Santikellur 的 ECP-TRN、Aseeri 的 MLP、Mursi 的 MLP）与**改进 LR 攻击**（基线）全部用 Keras 重写、同一 CPU 上跑，以排除框架/硬件差异，专门比较**数据复杂度**（成功建模所需 CRP 数）。
4. **衡量指标用“攻击成功率”而非准确率**：成功的攻击准确率都 ≥95%、失败的 ≤55%，因此用“独立攻击中预测准确率 >90% 的比例”作为指标，对阈值不敏感、更稳健。

## 二、贡献（论文自述五点，可归为“证成立论 + 证伪 + 开源”）

**证成（正面结果）**
1. XOR Arbiter PUF 用通用神经网络可**更快、更大安全参数、少一个数量级的 CRP** 被攻破（即便响应完全可靠），并驳斥 Nguyen 等“LR 最优”的说法。
2. 成果外溢：降低了 Interpose PUF 分割攻击的数据复杂度，并**首次实现前馈 Arbiter PUF 的通用 NN 攻击**——证明效益不止于 XOR Arbiter PUF 本身。
3. 复现三种神经网络攻击 + LR 攻击，给出穷尽公平对比（含异同与设计选择论证）。

**证伪（负面结果）**
4. **反驳** Mursi 等声称的“极低数据复杂度”，定位其原因是 CRP 生成器 bug（约 20% 时延被误置零）。
5. **反驳** Nguyen 等“LR 攻击数据复杂度最低”的论断。

**开源**
6. 提供统一、易用的 Python 开源实现，集成进 pypuf 框架（分支 2021-mlp），并鼓励社区公开攻击代码。

## 三、实验部分

| 实验 | 目标 | 关键结论 |
|---|---|---|
| **IV. 改进 LR 基线** | 给出对比基准 | LR 数据复杂度随 k 指数增长（k=10≈13 亿、k=12≈10¹²）；改进主要缩短墙钟时间，不改变指数态势 |
| **V. ECP-TRN（Santikellur）** | 复现并检验秩 R 收益 | 正确训练时只有 1 个分量模型有用；R 秩 ≤ R 次独立 1 秩；只能复现 4-XOR，≥7-XOR 失败，质疑其“最低数据复杂度” |
| **VI. Aseeri MLP** | 复现首个 >4 链 NN 攻击 | 全部复现并扩展到 64 位 9-XOR、128 位 8-XOR |
| **VII. Mursi MLP（核心）** | 复现 + 纠错 + 全面评估 | 定位 bug；有效 CRP 上仍比 LR 低一个数量级（64 位：k=4→150k，k=9→45M，k=11→325M）；对噪声鲁棒；可替代 LR 做分割攻击((1,7)-iPUF 用 6M CRP 数分钟搞定)；真实 FPGA 数据验证 |
| **VIII. 比较** | 公平横向对比四种攻击 | Mursi MLP 数据复杂度最低且优势仅体现在 >4 链；tanh（零均值）优于 ReLU |
| **IX. FF-APUF 攻击** | 扩展到前馈 PUF（仿真 + 3 块 Artix-7 FPGA） | 无需知道环模式即可攻 10 环 FF-APUF 与 8-XOR 同质 FF-APUF；异质环则失败（饱和 60%） |

**一句话实验结论**：把“神经网络建模攻击”从若干名声在外的 PUF 设计（XOR Arbiter、Interpose、前馈 Arbiter 及其 XOR 变体）上系统验证了一遍，证明它数据复杂度更低、攻击面更广，因此应纳入 PUF 安全分析的标准工具箱——同时用可复现的代码纠正了文献中两处被夸大的结论（Mursi 的极低数据复杂度、Nguyen 的“LR 最优”）。
